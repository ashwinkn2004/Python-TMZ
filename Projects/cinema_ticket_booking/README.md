# 🎬 Cinema Ticket Booking

A simple, friendly Python app to manage movie ticket bookings.

## About

This project provides a minimal system to browse movies, book seats, and manage reservations. It's intentionally small and easy to extend — more features and docs will be added later.

## Features (basic)
- Book and cancel tickets
- View current bookings
- Admin and user entry points (`admin.py`, `user.py`, `main.py`)

## Quick start

1. Ensure you have Python 3.8+ installed.
2. From the project folder, run:

```bash
python main.py
```
